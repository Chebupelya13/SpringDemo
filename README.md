# Demo Bank System

REST API сервис для обработки заявок на кредит и работы с кредитными договорами.

## Описание проекта

Приложение представляет собой банковскую систему, которая позволяет:
* Управлять пользователями (создание, поиск по различным критериям: ФИО, телефон, паспорт).
* Создавать и обрабатывать заявки на кредит (указание суммы и срока, получение списка заявок пользователя).
* Работать с кредитными договорами (создание договора на основе одобренной заявки, подписание договора).

Проект использует архитектуру на базе Spring Boot и реляционной базы данных PostgreSQL с доступом через Hibernate.

## Стек технологий

* **Java 17**
* **Spring Boot 3** (включая Web, Data JPA/Hibernate)
* **PostgreSQL** (хранение данных)
* **Hibernate** (ORM для работы с базой данных)
* **Springdoc OpenAPI (Swagger)** (документирование API)
* **Maven** (сборка проекта и управление зависимостями)

## Предварительные требования

Перед запуском проекта убедитесь, что в вашей системе установлены:
* JDK 17
* Maven 3.6+
* PostgreSQL 12+

## Настройка базы данных

Для корректной работы приложения необходимо настроить базу данных PostgreSQL.

В корне проекта находится файл `configureDB.sql`. С его помощью можно создать пользователя, базу данных и необходимые таблицы.
Вы можете выполнить скрипт в вашей СУБД или командной строке `psql`:

```bash
psql -U postgres -f configureDB.sql
```

Этот скрипт создаст:
- Пользователя `bank_user` с паролем `1234`
- Базу данных `bankdb`
- Таблицы: `users`, `employment_periods`, `applications`, `agreements`.

Убедитесь, что параметры подключения в файле `src/main/resources/application.properties` (если вы его дополните) соответствуют данным из скрипта.

## Запуск приложения

Для запуска приложения локально используйте Maven:

```bash
./mvnw spring-boot:run
```
или если у вас установлен Maven:
```bash
mvn spring-boot:run
```

Приложение по умолчанию запустится на порту `8080`.

## Документация API (Swagger UI)

Приложение включает встроенную документацию API, сгенерированную с помощью Springdoc OpenAPI.
После успешного запуска приложения, интерфейс Swagger UI доступен в браузере по следующему адресу:

**[http://localhost:8080/swagger-ui.html](http://localhost:8080/swagger-ui.html)**

Здесь вы можете посмотреть описание всех доступных эндпоинтов для `UserController`, `ApplicationController` и `AgreementController`, а также протестировать их прямо из браузера.

### Основные эндпоинты

* **Пользователи (`/api/users`)**: получение списка, поиск по фильтрам, создание.
* **Заявки (`/api/applications`)**: получение всех или одобренных заявок, поиск заявок пользователя, создание новой заявки.
* **Договоры (`/api/agreement`)**: получение, создание, подписание договоров и поиск по пользователю/заявке.
