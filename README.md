# Demo Bank System

REST API сервис для обработки заявок на кредит и работы с кредитными договорами.

## Описание проекта

Приложение представляет собой банковскую систему, которая позволяет:
* Управлять пользователями (создание, поиск по различным критериям: ФИО, телефон, паспорт, а также прикрепление фото).
* Создавать и обрабатывать заявки на кредит (указание суммы и срока, получение списка заявок пользователя).
* Работать с кредитными договорами (создание договора на основе одобренной заявки, подписание договора).
* Управлять доступом с помощью ролевой модели (USER, ADMIN) и JWT-авторизации.

Проект использует современную архитектуру на базе Spring Boot, реляционной базы данных PostgreSQL с доступом через Hibernate, S3-совместимого хранилища MinIO для файлов и Redis для кэширования.

## Стек технологий

* **Java 17**
* **Spring Boot 3** (включая Web, Data JPA, Security)
* **Spring Security + OAuth2 (JWT)** (аутентификация и авторизация)
* **PostgreSQL** (основное хранилище данных)
* **Hibernate** (ORM для работы с базой данных)
* **Liquibase** (управление миграциями схемы БД)
* **Redis** (кэширование данных)
* **MinIO** (S3-совместимое хранилище для фотографий и файлов)
* **MapStruct** (генерация мапперов между Entity и DTO)
* **Lombok** (сокращение шаблонного кода)
* **Springdoc OpenAPI (Swagger)** (документирование API)
* **Docker / Docker Compose** (контейнеризация инфраструктурных зависимостей)
* **Maven** (сборка проекта и управление зависимостями)

## Предварительные требования

Перед запуском проекта убедитесь, что в вашей системе установлены:
* JDK 17
* Maven 3.6+
* PostgreSQL 12+ (или Docker для запуска в контейнере)
* Docker и Docker Compose (для запуска Redis и MinIO)

## Настройка и запуск инфраструктуры

Для корректной работы приложения необходимо запустить сопутствующие сервисы (Redis и MinIO) и настроить базу данных PostgreSQL.

1. **Запуск Redis и MinIO через Docker Compose:**
   В корне проекта находится файл `docker-compose.yml`. Для запуска сервисов выполните команду:
   ```bash
   docker-compose up -d
   ```
   *MinIO будет доступен по портам 9000 (API) и 9001 (Web UI). Redis — по порту 6379.*

2. **Настройка базы данных PostgreSQL:**
   Вам необходимо создать пустую базу данных в вашем PostgreSQL сервере (например, с именем `bankdb`) и пользователя с правами доступа к ней.

   *Структура таблиц и базовые данные (роли) создаются автоматически при запуске приложения с помощью Liquibase (миграции лежат в `src/main/resources/db/changelog`).*

   Параметры подключения к базе данных настраиваются в файле `src/main/resources/database.properties` или через переменные окружения, передаваемые приложению.

## Запуск приложения

Для запуска приложения локально используйте Maven:

```bash
./mvnw spring-boot:run
```
или если у вас установлен Maven глобально:
```bash
mvn spring-boot:run
```

Приложение по умолчанию запустится на порту `8080`.

## Аутентификация и безопасность

API защищено с помощью Spring Security. Для доступа к большинству эндпоинтов (кроме создания пользователя и документации) требуется наличие JWT токена.

1. Токен можно получить через эндпоинт авторизации (например, `/api/auth/token`), передав логин и пароль.
2. Полученный токен необходимо передавать в заголовке `Authorization` в формате `Bearer <token>`.
3. Некоторые эндпоинты (например, управление всеми договорами `/api/agreement/**`) требуют прав Администратора (`ROLE_ADMIN`).

## Документация API (Swagger UI)

Приложение включает встроенную документацию API, сгенерированную с помощью Springdoc OpenAPI.
После успешного запуска приложения, интерфейс Swagger UI доступен в браузере по следующему адресу:

**[http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui.html)**

Здесь вы можете посмотреть описание всех доступных эндпоинтов для всех контроллеров, а также протестировать их прямо из браузера (включая авторизацию по токену).

### Основные разделы API

* **Аутентификация (`/api/auth`)**: получение JWT токенов.
* **Пользователи (`/api/users`)**: получение списка, поиск по фильтрам, создание нового пользователя (открытый эндпоинт).
* **Фотографии (`/api/photos`)**: загрузка и получение фотографий пользователя/заявки через MinIO.
* **Заявки (`/api/applications`)**: получение всех или одобренных заявок, поиск заявок пользователя, создание новой заявки.
* **Договоры (`/api/agreement`)**: получение, создание, подписание договоров и поиск по пользователю/заявке.
